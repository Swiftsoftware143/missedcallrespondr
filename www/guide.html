Overview

MissedCall Respondr is a call-response and follow-up automation platform. It captures incoming call data, lets you define custom response rules, sends automated text/callback replies, tracks follow-ups, and manages your contacts — all from one dashboard.

Built for businesses that never want to miss a lead or client callback, MissedCall Respondr helps you close the loop on every inbound call.

Dashboard

The Dashboard is your command center. It displays high-level metrics for the current day (or date range you select) so you can see at a glance how your call traffic is performing.

KPI Cards

Metric Description
Total Calls All inbound calls for the selected period.
Missed Calls Calls that went unanswered.
Answered Calls Calls that were picked up.
Voicemails Voicemail messages left by callers.
Follow-ups Pending Open follow-up tasks that haven't been completed.
Response Rate Percentage of calls that received an automated response.

Charts & Visualizations

Below the KPI cards you'll find a call volume chart (hourly or daily breakdown) and a missed vs. answered pie/bar chart. These visuals update in real time as new calls come in.

Recent Activity Feed

A scrolling list of the latest calls and system actions so you can keep an eye on what happened most recently without leaving the dashboard.

💡 Pro Tip Use the date-range picker at the top of the dashboard to view historical data — yesterday, last week, or a custom range.

Call Log

The Call Log is a sortable, searchable table of every inbound call. Each entry records who called, when, how long the call lasted, and what happened.

Table Columns

Column Description

Phone NumberCaller's phone number.
Date & TimeWhen the call came in (your timezone).
DurationLength of the call (if answered).
StatusMissed, Answered, Voicemail, or Blocked.

Filtering & Searching

  • Search bar — type any name or phone number to narrow results.
  • Status filter — show only Missed, Answered, or Voicemail calls.
  • Date range — pick a start and end date.

Call Detail View

Click a row or the View button to open the call detail panel, which shows:

  • Full caller info and linked contact profile
  • Call timeline (ring, answer, hang-up)
  • Voicemail playback & transcription (if applicable)
  • Auto-response sent (if any) and its delivery status
  • Internal notes (add your own)

Response Rules

Response Rules are the heart of MissedCall Respondr. They define when and how the system automatically replies to incoming calls.

Creating a Rule

  1. Navigate to Response Rules in the sidebar.
  2. Click + New Rule.
  3. Fill in the rule fields (see table below).
  4. Click Save. The rule is evaluated on every inbound call.
Field Description
Rule NameA label to identify the rule (e.g., "After-Hours Auto SMS").
Trigger ConditionWhen to fire: All Missed Calls, Specific Numbers, Time-of-Day, Day-of-Week, or a combination.
Response TypeSMS (send a text) or Callback (queue a return call).
Message / TemplateThe text to send — type a custom message or select a saved template.
ScheduleOptionally restrict when the rule is active (business hours, 24/7, custom).
PriorityRules are evaluated in priority order (1 = highest).
EnabledToggle the rule on/off without deleting it.

Rule Evaluation Order

Rules are evaluated by priority (lowest number first). The first matching rule fires and its action is executed. Lower-priority rules are skipped for that call.

Managing Rules

  • Edit — click the pencil icon on any rule row.
  • Delete — click the trash icon (confirmation required).
  • Reorder — drag-and-drop or adjust the priority field.
📌 Example Rule

Name: "Weekend Office Hours Follow-up"
Trigger: Missed calls on Saturday & Sunday
Response: SMS — "Hi {{name}}, we missed your call. We'll reach out on Monday. — {{company}}"

Follow-ups

Follow-ups are tasks assigned to calls, contacts, or created manually. They ensure nothing slips through the cracks.

Creating a Follow-up

  1. Go to Follow-ups.
  2. Click + New Follow-up.
  3. Fill in the details:
    • Title — brief description (e.g., "Call back John re: quote")
    • Assigned To — team member (if multiple users)
    • Due Date / Time — deadline for the follow-up
    • Priority — Low, Medium, High, Urgent
    • Status — Pending, In Progress, Completed, Cancelled
    • Notes — any context or instructions
  4. Click Save.

Auto-generated Follow-ups

When a response rule sends an SMS or queues a callback, the platform can automatically create a follow-up task linked to that call. Enable this option in the rule editor.

Status Tracking

Filter follow-ups by status (Pending, In Progress, Completed) or use the search bar to find a specific task. Completed items are archived for record-keeping.

Contacts

The Contacts section is a lightweight CRM that stores caller profiles. Contacts are auto-created from inbound calls (if the number is new) or can be added manually.

Managing Contacts

  • Add Contact — click + New Contact, enter name, phone, email, company, tags, and notes.
  • Edit — click any contact row to update their info.
  • Delete — remove a contact (confirmation required).
  • Search — type name, phone, or email to find a contact instantly.

Contact Detail Page

Opens a full profile showing:

  • Contact info (name, phone, email, company)
  • Call history — every call from this contact
  • Linked follow-ups — open and completed tasks
  • Notes — internal notes added by your team
💡 Pro Tip Tag your contacts (e.g., "VIP", "Lead", "Client") to build smart response rules that trigger different responses based on contact tags.

Message Templates

Message Templates are reusable text snippets with optional variable placeholders that are replaced dynamically when a response is sent.

Available Variables

Variable Replaced With
{{name}}Caller's name from Contacts (or "there")
{{phone}}Caller's phone number
{{company}}Your company name (from Settings)
{{time}}Current time when the response is sent
{{date}}Current date when the response is sent
{{duration}}Call duration (if answered)

Creating a Template

  1. Go to Message Templates → + New Template.
  2. Enter a name (e.g., "After-Hours SMS").
  3. Write your message body, inserting variables with {{}} syntax.
  4. Click Save. The template is now available in the Response Rules editor.
📌 Example

Hi {{name}}, thanks for calling {{company}}. We received your call at {{time}} and will follow up shortly. If this is urgent, please call us back directly.

Editing & Deleting

Templates can be edited or deleted from the same list. Deleting a template does not affect rules that already used it — the text is copied at rule-save time.

Voicemails

The Voicemail section lists every voicemail left by callers. Each entry shows the caller, duration, transcription status, and an audio player.

Transcription Status

  • Pending — audio is being processed.
  • Completed — transcript is available.
  • Failed — transcription could not be generated (retry available).

Audio Playback

Click the play button on any voicemail row to hear the recording in your browser. Use the volume slider and seek bar to control playback.

Taking Action

From the voicemail detail you can:

  • Create a Follow-up task linked to this voicemail
  • Send an SMS reply
  • Add the caller to Contacts (if not already saved)
  • Download the audio file

Integrations

Integrations let you connect MissedCall Respondr with external services. Each integration has a status indicator (Connected / Disconnected) and a Test Connection button.

Available Integrations

Integration Purpose
Twilio / VoIP ProviderReceives inbound call data and sends SMS/callback actions.
Email (SMTP)Sends email notifications for missed calls, follow-up reminders, etc.
WebhookHTTP POST callbacks to your own server when calls come in.
Zapier / MakeLow-code automation triggers to connect 2000+ apps.
SlackPosts call notifications to a Slack channel.

Configuring an Integration

  1. Click the integration card to open its configuration panel.
  2. Enter the required credentials (API key, webhook URL, etc.).
  3. Click Save — the integration status updates immediately.
  4. Click Test Connection to verify everything works.
⚠️ Important Always test a new integration before relying on it in production. The Test Connection button sends a sample payload to validate your credentials.

Settings

The Settings page manages your account, company profile, security, and API keys.

Account Settings

  • Profile — your name, email, phone, timezone.
  • Company — business name, address, logo (used in templates via {{company}}).
  • Password — change your login password.

API Keys

Generate and manage API tokens for programmatic access to the MissedCall Respondr API. Each key can have a label (e.g., "Production Webhook") and an expiration date.

  • Generate — click + New API Key. Copy the key immediately — it's shown only once.
  • Revoke — delete a key that is no longer needed.

Notification Preferences

Choose how you're alerted when calls come in:

  • Email notifications for missed calls
  • SMS alerts to your phone
  • Daily/weekly summary digest

Business Hours

Set your default business hours and timezone. These are referenced by response rules that are configured for "Business Hours Only" or "After Hours".

Frequently Asked Questions

How does MissedCall Respondr receive call data?

Your VoIP provider (Twilio, Telnyx, etc.) sends webhooks to MissedCall Respondr's API. Configure the webhook URL from your provider's dashboard to point to https://missedcallrespondr.com/api/v1/calls/incoming.

Can I have multiple response rules active at the same time?

Yes. Rules are evaluated by priority. Only the first matching rule fires per call. You can have dozens of rules with different conditions and priorities.

What happens if no rule matches a call?

The call is logged in the Call Log with status Missed or Answered, but no automated response is sent. You can still handle it manually from the call detail screen.

Are message templates required for SMS responses?

No. You can type a custom message directly in the rule editor. Templates are a convenience when you use the same message across multiple rules.

Can I export my call data?

Yes. Use the Export button in the Call Log to download a CSV file of all calls for the current filter or date range.

What variable syntax does the app support?

Use double-curly-brace syntax: {{name}}, {{phone}}, {{company}}, {{time}}, {{date}}, {{duration}}. Variables are case-sensitive.

How do I reset my password?

On the login page, click "Forgot Password?" and enter your email address. You'll receive a password reset link. You can also change your password in Settings → Password while logged in.

What happens to voicemails after they're transcribed?

Voicemails are stored indefinitely unless deleted manually. The transcript and audio file remain available in the Voicemails section and linked to the original call record.

Is there a mobile app?

The MissedCall Respondr web app is fully responsive and works on mobile browsers. There is no native iOS/Android app at this time.

How do I contact support?

Email support at support@missedcallrespondr.com or submit a request through the app using the Help link in the bottom-left of the sidebar.
